# Юнискул — демонстрационная платформа

Отдельный интерактивный прототип для согласования интерфейса, без подключения к рабочему сайту гимназии.

Сайт: https://nikalikeone.github.io/unischool-demo/

Кабинет: https://nikalikeone.github.io/unischool-demo/learn/

## Вход и публикация

Логин демопрофиля Александры Соколовой: `demo`. Пароль передан владельцу отдельно; открытым текстом в репозитории не хранится. Сессия действует 7 дней, доступен выход из профиля. Без входа кабинет перенаправляет на форму авторизации.

**Это не защищённая LMS.** Проверка демопароля выполняется в браузере (PBKDF2), сессия хранится в localStorage; такой вход можно обойти. Размещать здесь реальные данные учеников, приватные переписки и платные уроки нельзя. Для рабочего запуска нужна серверная авторизация и проверка прав доступа.

GitHub Pages публикует готовую сборку из `docs/` ветки `main`. Сборка для публикации: `DEPLOY_BASE=/unischool-demo npm run build`. После изменений замените сборку в `docs/` содержимым `dist/` вместе с `.nojekyll` и отправьте изменения в GitHub. Пароли и другие секреты не добавляйте в исходники.

## Запуск

В этой рабочей папке используется установленный в родительском проекте Astro:

```sh
ASTRO_TELEMETRY_DISABLED=1 ../node_modules/.bin/astro dev --background
ASTRO_TELEMETRY_DISABLED=1 ../node_modules/.bin/astro dev status
ASTRO_TELEMETRY_DISABLED=1 ../node_modules/.bin/astro dev stop
ASTRO_TELEMETRY_DISABLED=1 ../node_modules/.bin/astro build
```

Публичная главная: http://127.0.0.1:4322

Учебный экран: http://127.0.0.1:4322/learn/

## Публичная главная

Тарифы «Юни 1» (990 ₽ за месяц) и «Юни 2» (1 790 ₽ за месяц) используют согласованные предварительные цены для макета. Сроки 1, 3 и 6 месяцев рассчитываются без скидок. Каталог позволяет выбрать 1–11 класс и прочитать пример программы предмета. Закрытые видео и задания предлагают выбрать тариф. Покупка открывает форму регистрации с сохранением класса, предметов и срока; форма проверяет обязательные поля и не позволяет выбрать один предмет дважды.

Формы не отправляют и не сохраняют персональные данные. После проверки формы показывается демонстрационный состав заказа, а не реальная оплата. Состав предметов и тем — примеры для согласования, не окончательная учебная программа.

Для самостоятельного использования папки выполните `npm install`, затем `npm run dev`.

## Проверяемые сценарии

- Вход по паролю, страница «Моё обучение», карточка доступного предмета, выход.
- Мини-тест после первого конспекта с автоматической проверкой без уведомления преподавателю.
- Общая закреплённая шапка: поддержка, уведомления, профиль.
- Содержание предмета и стрелки между видео, текстами и заданиями.
- Переключатель состояний первого задания в нижней панели прототипа.
- Первое задание: сдача закрыта / доступна / на проверке / доработка / принято.
- Второе задание читается всегда; сдача и переписка доступны только после принятия первого.
- После принятия первого задания сохраняется история, форма исчезает, появляется уведомление с переходом к работе.
- Вопрос преподавателю не отправляет работу на проверку.
- Черновики и демонстрационные работы сохраняются локально в браузере.
- Чат поддержки с автоматической подсказкой по вопросам к уроку.
- Раздел «Как учиться в Юнискул» пока содержит заглушку для будущих инструкций.

## Ограничения

Все имена, предметы, сроки и отметки — демонстрационные. Прогресс сохраняется только в текущем браузере, без синхронизации между устройствами. Видеоплеер показывает короткую анимированную демонстрацию, настоящего учебного видео нет. Сообщения не отправляются сотрудникам. Прикреплённые файлы не загружаются: сохраняются только их названия. Серверная авторизация, роли, ограничения доступа, платежи и административный интерфейс пока не реализованы. Кнопки оплаты не проводят платежей. Не вводите реальные персональные данные.

Вопросы после принятия последнего задания ещё не согласованы; этот сценарий не реализован. Прототип предназначен для проверки интерфейса ученика. Общая шапка впоследствии используется и в остальных ролях.

Цвета взяты из существующего проекта Онлайн-гимназии: синий `#4682B4`, зелёный `#22C55E`, мятный `#10B981`, кнопки оплаты `#FF6B35`. Шрифты — Playfair Display для заголовков, Manrope для интерфейса; локальные файлы шрифтов.
