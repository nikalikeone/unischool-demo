# Юнискул — следующий этап после демоверсии

## Подтверждённые условия

- После авторизации ученик попадает на публичную главную с предложениями. Переход к урокам — через «Моё обучение». Преподаватель после входа открывает свой рабочий кабинет.
- Юни1 — 99 ₽/месяц, 1 предмет; Юни2 — 149 ₽, 2; Юни3 — 199 ₽, 3; Юни4 — 249 ₽, 4.
- ЮниBig — 399 ₽/месяц, 4 предмета и видеолекции. ЮниBig Pro — 999 ₽/месяц, также конспекты по каждой теме.
- BigProMax — 5 199 ₽/месяц: все онлайн-занятия по расписанию по одному предмету и материалы по трём дополнительным. Разовое занятие — 1 399 ₽. Длительность занятий, расписание и условия записи ещё нужно определить.
- Дневные суммы сохранены в конфигурации, но отдельная покупка на день пока не показывается. Основной период — месяц.
- «Как учиться в Юнискул» входит в каждый тариф.
- Преподаватель закрепляется за предметом конкретного ученика или нескольких учеников.

## Порядок работ

1. Серверная база и настоящая авторизация: роли, безопасные сессии, восстановление доступа, проверка прав на сервере. Текущий GitHub Pages — только публичное демо, не защищённое хранилище.
2. Админкабинет: управление пользователями, назначениями, предметами, классами, тарифами и расписанием. Наполнение через аккаунт администратора, без правок кода разработчиком.
3. Редактор учебного материала: темы, короткие видео, видеолекции, конспекты, тесты с правильными ответами, письменные задания, черновики, предпросмотр и публикация. Учителю — только назначенные материалы в рамках утверждённых прав.
4. Хранилище видео и файлов с доступом по тарифу; загрузка с проверкой типа/размера. Встроенный плеер без перехода на сторонние страницы.
5. Заполнить один предмет и проверить путь целиком: покупка, доступ, урок, тест, сдача, переписка, отметка, окончание доступа. Затем масштабировать наполнение.
6. Платёжный сервис: реальный заказ и сумма на сервере, подтверждение оплаты, выдача доступа только после подтверждения, защита от повторной обработки, истечение срока, продление. Для BigProMax — запись на занятия и правила посещения.
7. Акции: утверждённые базовые цены и условия, единая дата окончания с часовым поясом. Таймер не перезапускается при обновлении страницы; после окончания сервер перестаёт применять акцию.
